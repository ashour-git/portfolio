# Hero performance ledger (2026-11-17)

Device: Intel UHD Graphics 630 (D3D11), Chrome headless with GPU, viewport
1850 x 1000 at 125% scaling. "Page" rows: 12 s of requestAnimationFrame after a
6 s warm-up, 3 runs. "GPU" rows: shader alone, 10 draws per readback, median.
An empty page measures 60 fps, 0 long frames in the same harness.

| Idea | Baseline -> Result | Verdict | Why |
|---|---|---|---|
| Analytic weak-field bending outside r = 14.5 (skip integration where nothing emits) | GPU full-res 90 ms -> 45 ms | kept | Half the steps were spent in empty space |
| Two layers: soft field + sharp feathered core; adaptive resolution both ways | page 7 fps -> 8 fps | kept | Shader was no longer the cap (see below); needed for sharpness at any budget |
| Remove the 30 fps cap; time-based easing | (part of the row above) | kept | Motion paced by time, not frames |
| Code stream: sprite-sheet glyphs instead of rotated fillText | page 8.5 fps -> 48 fps | kept | Rotated, non-uniformly scaled text re-rasterised ~1000 glyphs per frame |
| Funnel moved from animated SVG (+ blend) into the canvas | (bundled with the row above) | kept | SVG transform animation repainted the layer per frame |
| Controller recovery threshold 14.5 ms -> 18.2 ms | stuck at floor -> holds level 2 | kept | 14.5 ms is unreachable at 60 Hz vsync |
| Core square 1.15 f -> 0.72 f | core GPU 17.7 ms -> about 7 ms | kept | Core pixels cost 2.3x field pixels; ring and shadow sit inside 0.22 f |
| Haze only near the disk plane; stop rays falling inside the photon sphere | GPU 47.7 -> 45.4 ms | kept | Small, in line with expectation; no visual change |
| Neural network moved from animated, masked SVG into the canvas | page 43 fps -> 58.5 fps, long frames 17% -> 2-3% | kept | Last full-layer repaint per frame |
| Crisp starfield in the cached canvas layer; shader stars only in the core | 58.5 -> 55-60 fps (noise) | kept | Neutral cost, removes blurred star blobs |

Guard: rerun `perf.js` (frame pacing) and `bench-shader.js` (GPU time) from the
QA scratch scripts before changing the shader or adding anything animated to
the hero. Budget: 58+ fps and under 5% long frames on the device above.
